# RelicTrek 视觉设计原型 — 执行计划

## 目标
创建5个完整、高质量、独立的HTML原型页面，每个展示一个独特的寻宝冒险主题视觉风格。
每个原型都是完整的攻略页面（含导航、侧边栏、6模块内容），不是粗糙的卡片预览。

## 5个设计方向

### 1. Cave Explorer（洞穴探险家）
- **色彩**: 深褐黑底 + 琥珀金 + 火把橙
- **氛围**: Minecraft洞穴深处，火把照亮岩壁，发现钻石矿脉的兴奋感
- **纹理**: 岩壁质感、矿石闪光点、火把动态光晕
- **字体**: 粗体标题带微弱发光效果

### 2. Pirate Treasure（海盗宝藏）
- **色彩**: 深海蓝黑 + 金币金 + 航海铜
- **氛围**: 船长室里的藏宝图，罗盘指向未知岛屿，海浪声在耳边
- **纹理**: 羊皮纸质感、罗盘图案、海浪纹路
- **字体**: 古典衬线标题，手写风格注释

### 3. Dungeon Delver（地下城探索者）
- **色彩**: 深邃紫黑 + 魔法紫 + 符文青
- **氛围**: Terraria地下城/塞尔达神庙，魔法符文在墙上发光，神秘力量涌动
- **纹理**: 符文图案、魔法粒子、暗紫光晕
- **字体**: 神秘哥特风格标题

### 4. Relic Ruins（遗迹废墟）
- **色彩**: 沙石灰 + 古铜 + 石刻褐
- **氛围**: Elden Ring的地下遗迹，风沙中的古代神庙，石碑上的铭文
- **纹理**: 风沙划痕、石刻纹理、古迹斑驳
- **字体**: 史诗级厚重标题，带历史沧桑感

### 5. Current Pure C（当前纯C风格）
- **色彩**: 保持现有的代码编辑器风格
- **作为对比基准**，让用户看到改进有多大

## 执行阶段

### Stage 1: 并行创建5个完整原型（5个子代理同时工作）
- 每个子代理负责一个设计方向的完整HTML页面
- 页面结构: 顶部导航 + 滚动Slogan + 左侧游戏导航 + 中间6模块攻略内容 + 右侧栏
- 使用模拟的真实内容（Elden Ring的某个物品攻略）
- 独立CSS内嵌，不依赖外部样式表
- 每个页面都要精美到可以直接截图当设计稿

### Stage 2: 更新选择页面
- 重写index.html，本身也要精美
- 5个卡片改为5个缩略图+简要描述
- 点击跳转到完整原型

### Stage 3: 部署
- 部署design-prototypes文件夹到线上
- 提供Git推送命令

## 质量标准
- 每个原型必须有完整的6模块攻略结构
- 必须有顶部导航+侧边栏+内容区三栏布局
- 视觉必须独特、精美、有沉浸感
- 必须是响应式（桌面端优先）
- 必须有中英文切换按钮（至少UI上有）
