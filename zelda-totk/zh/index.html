塞尔达传说：王国之泪

10件必备余料建造武器、防具和升级。每个龙之泪位置、每个钻石、每个海拉鲁/天空/地底的隐藏捷径。

大师之剑

★★★★★ Late Game

退魔之圣剑。在天空、地面和地底恢复它的全部力量。遍布三个区域的12个龙之泪。

海利亚盾

★★★☆☆ Mid Game

90防御力，游戏中最强的盾。隐藏在海拉鲁城堡船坞，或在完成漫长任务链后以高价购买。

光鳞之枪

★★★★☆ Mid Game

米法的遗产武器。需要卓拉长枪、钻石和打火石 — 一路前往卓拉领地。22基础攻击力 + 水战士加成。

七宝匕首

★★★★☆ Mid Game

乌尔波扎的标志性刀刃。需要格鲁德之刀 + 钻石 + 打火石，在格鲁德小镇制作。32攻击力，附带闪电充能。

大鹫弓

★★★☆☆ Mid Game

力巴尔的爱用武器。需要飞燕弓 + 钻石 + 木柴捆，在利特村制作。三段射击，28×3伤害。

碎岩巨剑

★★★★☆ Mid Game

达尔克尔的标志性碎岩锤。需要碎岩剑 + 钻石 + 打火石，在鼓隆城制作。36攻击力，一击碎矿。

鬼神套装

★★★★★ Late Game

攻击力提升×3，最强的战斗防具。需要完成跨越多个区域的整个梅祖拉的假面彩蛋任务链。

蛮族套装

★★★★☆ Mid-Late Game

每件提升攻击力，散落在海拉鲁的三座迷宫中获得。每座都是带有隐藏地下入口的巨大迷宫。

勇者皮衣

★★★☆☆ Mid Game

5 defense + 大师之剑 beam boost. Requires finding the well-hidden tailor and collecting rare materials across multiple regions.

夜光套装

★★★☆☆ Early-Mid Game

夜间发光骨制防具，夜晚攻击力加成。需要从地底收集魄并找到神秘造型师。
