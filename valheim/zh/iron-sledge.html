铁链锤

难度：★★★★☆ 中后期

铁战锤是英灵神殿中终极的双手锤，将毁灭性的75钝击伤害与巨大的范围效果（AoE）冲击半径结合，使其成为采矿、群控和Boss战的首要工具。在击败亚格鲁斯后在盖尔德台合成，这把武器代表了平原时代工程的巅峰以及进入迷雾之地终局的桥梁。与破鹿锤等前期武器不同，铁战锤是真正的终局工具，陪伴你通过平原最困难的内容并进入迷雾之地。

铁链锤的决定性特征是其AoE伤害 cone。每次挥击产生冲击波，伤害 wielder 前方180度 arc 内的所有敌人。此冲击波从玩家延伸约4米，允许你同时击中多个目标。伤害是纯钝击类型，使其对骷髅、史莱姆和任何低钝击抗性生物特别有效。铁链锤也是英灵神殿中唯一能单次挥击伤害多个矿床的唯一武器，使其成为采矿效率的无争议王者。

英灵神殿的生态区进阶——草地 → 黑森林 → 沼泽 → 雪山 → 平原 → 迷雾之地 → 灰烬之地——将铁战锤定位在沼泽与平原时代的交汇处。合成配方结合了沼泽材料（古树皮、精英尸鬼战利品）和平原材料（尤弥尔之肉），使其成为跨生态区成就，标志着你掌握了多个生态系统。

铁链锤需要四种材料：古代树皮、铁、伊米尔肉和精英尸鬼奖杯。古代树皮从沼泽的古树采集。铁从沼泽地下墓穴开采的废铁熔炼。伊米尔肉从黑暗森林的商人哈尔多尔处购买，每块120金币。精英尸鬼奖杯从精英尸鬼掉落——在沼泽地下墓穴和墓穴中发现的强大星 rank 变体。每种材料讲述了一个穿越多个 hostile 生态区的生存故事。

在Boss进阶路线——赤血灵鹿（草地）→ 古树长老（黑森林）→ 邪骨恶灵（沼泽）→ 冰霜龙母（雪山）→ 亚格鲁斯（平原）——中，铁战锤位于亚格鲁斯层级。击败亚格鲁斯提供撕裂灵体，用于建造盖尔德台——同时解锁铁战锤和刺球钉锤的终局合成台。这种依赖链使铁战锤成为真正的后期成就。

合成配方

铁战锤在盖尔德台合成，需要亚格鲁斯的撕裂灵体建造。这是合成刺球钉锤的同一个合成台，所以击败亚格鲁斯同时解锁两把终局武器。盖尔德台需要：1个撕裂灵体 + 20黑金属 + 5个黑核 + 5焦油。建造在锻造台附近以便使用。

合成台：加拉德尔工作台

工作台材料：20细木 + 20黑金属 + 5火巨人精华 + 1撕裂之魂

品质4（最高级）的总材料：100古代树皮 + 300铁 + 10伊米尔肉 + 1精英尸鬼奖杯。铁链锤的基础耐久为200，背刺加成为3倍。其攻击速度为每挥2.46秒——比单手武器慢，但与其巨大伤害和AoE能力相称。次要攻击是强力的地面猛击，产生更大的冲击波半径（约6米）并造成2倍伤害，以显著更高的体力消耗为代价。此地面猛击对 tightly packed 的敌人群体是毁灭性的。

关键提示：无论品质等级，你只需要一个精英尸鬼奖杯。从品质1升级到4时奖杯不被消耗——只在初始合成时需要。这在英灵神殿配方中是不寻常的，意味着找到一个精英尸鬼奖杯就足以获得完全升级的武器。

材料及获取地点

古代树皮——沼泽树木

古代树皮在沼泽生态区砍伐古树时掉落，需用青铜斧或更好的工具。古树是独特的扭曲树木，具有 dark bark，为沼泽独有。每棵树产出5-8古代树皮。品质4需要100古代树皮，大约需要15-20棵树。

安全提示：沼泽充满敌意，有毒性敌人（史莱姆、软泥怪）、亡灵（尸鬼、精英尸鬼）、火生物（火精灵）和仅限夜晚的幽灵。始终在白天砍伐古代树皮以避免幽灵。带上抗毒蜜酒、好盾牌和可靠武器。在沼泽基地建造传送门以便快速撤退。

铁——沼泽地下墓穴采矿

铁从废铁熔炼，废铁用鹿角镐或更好的工具在沉没地下墓穴的泥泞废铁堆开采。每个废铁堆产出2-4废铁。熔炼比例为2废铁 + 1煤 = 1铁锭。品质4需要300铁锭，大约需要600废铁和300煤。

一个典型的沉没地下墓穴包含15-25个泥泞废铁堆，产出30-75废铁。600废铁需要计划突袭10-15个墓穴。沉没地下墓穴需要沼泽钥匙（黑暗森林的古树长老掉落）开启。每把钥匙可无限使用且不消耗。

伊米尔肉——商人购买

伊米尔肉从黑暗森林的商人哈尔多尔处购买，每块120金币。品质4需要10块，总计1200金币。金币从草地的埋藏宝藏（用许愿骨找到）、巨魔击杀、地下城箱子和向哈尔多尔出售宝石获得。

精英尸鬼奖杯——稀有掉落

精英尸鬼奖杯从精英尸鬼掉落——在沼泽地下墓穴和墓穴中发现的标准尸鬼的星 rank、更强变体。掉落率约为10-15%，意味着你可能需要击杀7-10个精英尸鬼才能获得一个奖杯。精英尸鬼比标准尸鬼更大，有更多生命值，并造成显著更多伤害。他们经常在沉没地下墓穴的更深 section 生成。

刷取技巧：精英尸鬼在更大的沉没地穴中有更高的刷新率。寻找有多个房间和长走廊的地穴。带毒抗蜜酒（软泥怪常伴随尸鬼）和银剑或霜牙钉锤。在刷取地穴附近建造传送门以便快速刷新循环。

最优路线

完整生态区进阶

草地 → 黑暗森林 → 沼泽 → 雪山 → 平原 → 迷雾之地 → 灰烬之地

提前准备路线（尽早开始）

  1. 沼泽阶段（早期） — 在为通用进阶刷铁时，砍伐你看到的每棵古树。目标在离开沼泽前获得100+古代树皮。击杀每个精英尸鬼——你需要他们的奖杯。
  2. 商人访问 — 在黑暗森林找到哈尔多尔。购买10块伊米尔肉（1200金）。如果金币不足，用许愿骨在草地刷埋藏宝藏。
  3. 铁储备 — 继续突袭沼泽地下墓穴直到你有300+铁锭。这比普通进阶中大多数玩家收集的铁更多，所以 plan 额外的墓穴 run。
  4. 击败亚格鲁斯 — 穿越雪山，击败冰霜龙母，进入平原，击败亚格鲁斯。用撕裂之魂建造加拉德尔工作台。
  5. 合成铁链锤 — 准备好所有材料，在加拉德尔工作台合成品质1-4的铁链锤。

因为铁链锤四种材料中的三种（古代树皮、铁、伊米尔肉）可以在击败亚格鲁斯前收集，准备充分的玩家可以准备好一切并在建造加拉德尔工作台后立即合成武器。唯一的限制因素是精英尸鬼奖杯，这依赖于RNG。

陷阱与常见错误

陷阱1：未提前刷古代树皮

古树只在沼泽中找到。许多玩家快速通过沼泽阶段，收集了铁但忽视了古树。当他们后来想合成铁战锤或霜牙钉锤时，必须返回沼泽。早期规划：击败邪骨恶灵后，在沼泽探险时总是采集古树皮。

陷阱2：忘记奖杯不消耗

精英尸鬼奖杯在将铁链锤从品质1升级到4时不被消耗。这在基于奖杯的配方中是独特的。许多玩家浪费数小时刷多个奖杯，以为每个品质等级需要一个。完全升级的铁链锤永远只需要一个精英尸鬼奖杯。

陷阱3：对单体目标使用地面猛击

次要地面猛击攻击消耗 enormous 体力，对单个敌人是浪费的。将其保留给3+敌人群体或采矿多个矿床。对抗单体目标，使用标准挥击——它以远 less 体力造成几乎相同的伤害。

陷阱4：双手 = 无盾牌

铁链锤是双手武器。使用时无法装备盾牌。这使你对 incoming 伤害 significantly 更脆弱。在平原或迷雾之地等危险生态区，面对死亡蚊或弓箭手时考虑切换单手武器加盾牌。铁链锤在受控 situation（采矿、基地清理）中 excels，但在 open combat 对抗远程敌人时可能 risky。

陷阱5：破坏自己的基地

铁链锤的AoE伤害影响所有可破坏物体，包括你自己的建筑 piece。基地内 careless 的地面猛击可以破坏箱子、合成台和墙壁。伤害也影响驯服的动物。进入基地时 always 卸下铁链锤，并 design 安全的户外区域用于测试挥击。

免费福利与解锁

1. 采矿效率之王

铁链锤是英灵神殿中最好的采矿工具。其AoE伤害同时击中多个矿床，其高钝击伤害快速破坏岩石构造。单次地面猛击可以 crack 黑暗森林中3-4个相邻的铜或锡矿床，或清除沼泽地下墓穴中 entire cluster 的泥泞废铁堆。对于大规模采矿作业，没有工具能接近铁链锤的效率。

2. 基地建筑碎片清理

为基地 construction 平整土地时，铁链锤的地面猛击 instantly 清除宽半径内的岩石、树木和灌木。用常规镐或斧需要数分钟的工作，铁链锤只需数秒。仅此一点就证明为任何喜欢大规模基地建设的玩家合成这把武器的合理性。

3. 事件防御专家

英灵神殿的随机事件——'森林在移动'（巨魔）、'沼泽的恶臭'（尸鬼）、'你被猎杀'（狼）和其他——向你的基地发送敌 wave。铁链锤是完美的防御武器，其AoE用几次挥击清除 entire wave。将自己 position 在 choke point 并让敌人向你袭来——地面猛击会完成其余工作。

4. 沼泽地下墓穴快速清理

返回沼泽获取额外铁（用于其他配方）时，铁链锤比任何其他武器更快清理墓穴。单次地面猛击可同时击杀多个尸鬼和史莱姆，宽挥击 arc 确保 enclosed 墓穴走廊中 nothing 幸存。曾经每墓穴需要15分钟现在只需5分钟。

5. 加拉德尔工作台 = 豪猪钉锤 access

为铁战锤建造盖尔德台同时解锁刺球钉锤配方。许多玩家将两把武器作为配套合成——刺球钉锤用于单体Boss伤害，铁战锤用于群控和采矿。这种组合让你为任何战斗做好准备。

6. 棍棒技能适用于所有锤类

使用铁链锤提升你的棍棒技能，这适用于所有锤类武器包括豪猪钉锤、铁锤、青铜锤甚至霜牙。高棍棒技能（50+）提供伤害加成、体力减少和 faster 攻击速度，覆盖 entire 武器类别。即使你主要用铁链锤采矿，技能 gain 使你所有其他近战武器受益。

铁链锤不仅仅是一把武器——它是文明的工具。它通过清理土地 build 你的基地，通过采矿 ore forge 你的其他武器，并 defend 你的家园对抗英灵神殿的荒野。当你持有铁链锤时，你不仅仅 armed；你是 empowered。每次挥击重塑周围的世界，每次地面猛击都是声明这片土地是你的。
