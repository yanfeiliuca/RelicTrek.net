Valheim（英灵神殿）

1200万维京勇士。9个生态区、5个Boss、奖励探索的合成系统。从草地到灰烬之地的旅途中10个定义你的必备武器和防具套装。

刺球钉锤

★★★★★ 终局

尖刺 + 细木 + 铁。终极钉锤——95钝击+47穿刺。击败亚格鲁斯并前往平原获取尖刺。

霜牙钉锤

★★★★★ 终局

银 + 尤弥尔之肉 + 冷冻腺 + 古树皮。93霜冻+40灵界伤害。英灵神殿中最强的元素武器。

黑金属剑

★★★★☆ 后期

黑金属 + 细木 + 亚麻线。95斩击伤害。击败邪骨恶灵，建造传送门前往平原，寻找丑怪村庄。

铁战锤

★★★★☆ 中后期

古树皮 + 铁 + 尤弥尔之肉 + 精英尸鬼战利品。范围效果战锤，75钝击伤害。挖矿和群战的完美选择。

尸鬼之牙

★★★★☆ 后期

古树皮 + 银 + 鹿皮 + 树液。游戏中最强弓——78穿刺+24毒素。前往沼泽寻找树液。

甲壳护甲套装

★★★★★ 终局

每件32护甲。来自迷雾之地探客的甲壳 + 黑金属。灰烬之地更新前最强的护甲。

狼皮护甲套装

★★★★☆ 后期

每件20护甲，霜冻抗性。银 + 狼皮 + 狼战利品。雪山生态区探索必备。

厚絮护甲套装

★★★★☆ 后期

每件26护甲。铁 + 亚麻线。迷雾之地前终局护甲——平原刷怪仍然有用。

破鹿锤

★★☆☆☆ 前期

核心木 + 鹿战利品 + 皮革。38钝击范围伤害。你的第一把真正武器——击败赤血灵鹿后立即合成。

青铜钉锤

★★★☆☆ 中期

木材 + 青铜 + 皮革。53钝击，对骷髅2倍伤害。带你通关沼泽和邪骨恶灵的武器。
